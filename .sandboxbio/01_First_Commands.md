
# Section 1.4 — Entering Your First Commands

Welcome to your first BMS-BOOST interactive Terminal exercise!

In this exercise, you will practice three commands introduced in the Day 0 workbook.

## Exercise 1 — Who am I?

The `whoami` command displays your current username.

In the terminal below, enter:

```bash
whoami
```

**Expected output:**

```text
sandbox
```

Notice that the username in this environment is `sandbox`. Your username on your own Mac will likely be different.

## Exercise 2 — Where am I?

The `pwd` command stands for *print working directory*. It displays your current location in the file system.

Enter:

```bash
pwd
```

Examine the directory path displayed.

Your output should resemble:

```text
/home/sandbox/github/mbaddoo/BMS-BOOST-Day0
```

## Exercise 3 — Display a message

The `echo` command displays text in the terminal.

Enter:

```bash
echo "Welcome to BOOST."
```

**Expected output:**

```text
Welcome to BOOST.
```

## Check Your Understanding

Before continuing, make sure you can answer these questions:

1. Which command displays your username?
2. Which command displays your current working directory?
3. What does the `echo` command do?

You have now completed your first interactive BMS-BOOST Terminal exercise!
