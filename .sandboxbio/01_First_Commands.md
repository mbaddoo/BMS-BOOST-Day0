
# Section 1.4 — Entering Your First Commands

Welcome to your first BMS-BOOST interactive Terminal exercise!

In this exercise, you will practice three commands introduced in the Day 0 workbook.

## Exercise 1 — Who am I?

The `whoami` command displays the username associated with your current terminal session.

In the terminal below, type `whoami` and press Return.

**Expected output:**

```text
sandbox
```

**What does this mean?**

The terminal displays `sandbox` because you are working in sandbox.bio's simulated computing environment. If you run the same command in Terminal on a Mac, you will see the Mac's username instead. 

Try it yourself: Compare the username displayed by `whoami` with the username shown in the Terminal prompt on a Mac. 

## Exercise 2 — Where am I?

The `pwd` command stands for *print working directory*. It displays your current location in the file system.

In the terminal below, type `pwd` and press Return.

**Expected output:**

```text
/home/sandbox/github/mbaddoo/BMS-BOOST-Day0
```

**What does this mean?**

The `pwd` command displays the full path to your current working directory-the folder where you are presently located in the file system. In sandbox.bio, this directory contains our BMS-BOOST GitHub repository.

Try it yourself: Look at the path returned by `pwd`. Notice that it begins with / and ends with BMS-BOOST-Day0. You don't need to memorize this path; simply recognize that it tells you where you are in the file system. 

## Exercise 3 — Display a message

The `echo` command displays text in the terminal.

In the terminal below, type `echo "Welcome to BOOST."` and press Return.

**Expected output:**

```text
Welcome to BOOST.
```

**What does this mean?**

The `echo` command displays the text you provide. In this example, the terminal prints `Welcome to BOOST.` exactly as written inside the quotation marks. 

Try it yourself: Run the command again, but replace `Welcome to BOOST.' with a short message of your own. Keep the quotation marks around your message. 

For example, type `echo "Roll Wave!"` and press Return. 

Notice that the terminal displays your new message.
